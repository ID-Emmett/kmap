# Research Skill

## 目标

通过可追溯证据形成项目事实，不把推测伪装成结论。

## 流程

```text
读取已有 research
→ 检查代码证据
→ 实际验证
→ 区分事实和推测
→ 输出结构化结论
```

## 执行规则

1. 先读取任务、相关 research、architecture、decisions 和 knowledge。
2. 为每个结论标记“已验证”“代码已确认”“待验证”或“未发现”。
3. 网络协议结论记录 URL 模板、状态码、响应头、压缩、格式、样本坐标和解析方法。
4. 数据字段结论记录样本范围、类型、覆盖率和异常，不从有限样本外推全量。
5. 发现冲突时同时保留证据，交由 Project Control 决策。
6. 只有经过验证且影响项目的事实才同步到 `KNOWLEDGE.md`。

## 输出

- 研究目标与范围。
- 证据来源和复现步骤。
- 已验证事实。
- 代码已确认但未运行的事实。
- 待验证和未发现内容。
- 对当前 Task、架构和风险的影响。
