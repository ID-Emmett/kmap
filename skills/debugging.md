# Debugging Skill

## 目标

通过可复现证据定位根因，以最小修改恢复正确行为。

## 流程

```text
复现
→ 收集证据
→ 定位根因
→ 最小修改
→ 回归测试
→ 记录知识
```

## 执行规则

1. 固定输入、环境、版本、浏览器、后端和复现步骤。
2. 区分网络、数据、解码、坐标、Geometry、GPU、交互和资源生命周期问题。
3. 使用日志、断言、Inspector、抓包、最小样本和性能标记收集证据。
4. 不用 fallback 零值、吞错、扩大重试或删除测试掩盖根因。
5. 修改范围只覆盖根因及必要回归保护。
6. 对 WebGPU 和 WebGL2 fallback 分别执行相关回归。
7. 只有已复现并验证的通用结论才写入 `KNOWLEDGE.md` 的 Bug/Environment 分类。

## 输出

- 复现条件与最小样本。
- 根因证据链。
- 修改内容和未修改边界。
- 自动/人工回归结果。
- 影响范围和剩余风险。
