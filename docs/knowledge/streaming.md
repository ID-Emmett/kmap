# StreamingEngine 已验证事实

更新日期：2026-09-15

## 实现与数据

- `Map3D` 的瓦片入口为 `packages/map3d/src/streaming/engine.ts`。
- 输入为真实 KYE XYZ MVT；Worker 通过 `@mapbox/vector-tile` 和 `pbf` 解码，OffscreenCanvas 输出 256/512 像素面纹理，中心线输出实例属性数组。
- 道路线宽以 CSS 像素为单位，由 TSL 按当前视图缩放计算；相邻父级和任意祖先数据使用相同地面线宽。回归覆盖跨数据层级的宽度换算与共享材质程序。
- Three.js WebGPU 使用共享平面几何、`MeshBasicNodeMaterial` 和共享 TSL 距离雾；每帧纹理上传上限为 1。
- 数据源最细三级面纹理为 512 像素，其余为 256 像素；256 CSS 像素 XYZ 语义支持连续缩放，目标最大数据层级取视图 zoom 的整数部分。
- 相机视锥与地面截止半径共同约束选片；邻接预取使用相同截止边界。
- 覆盖解析遍历完整祖先链，下载需求使用目标、两级覆盖、三级与五级基础覆盖。无底图的覆盖面立即显示，具有底图的细节执行 140 ms 淡入；缩小切换中的细层级淡出。
- 生命周期测试验证初始化复用、销毁资源、慢网并发上限、204 祖先覆盖和俯仰跳变覆盖。
- 条目在准入时执行硬上限；未显示缓存按当前需求、路线预测和附近基础覆盖的优先顺序回收。当前必要需求在上传队列中优先提交。
- 滚轮以 80 ms 时间常数按经过时间推进，60/120/170Hz 在同一时刻具有一致 zoom，并准确到达输入目标。

## 覆盖与高倾角专题事实

- 当前目标集合空间互斥；实际绘制集合可以包含覆盖同一区域的多个父子来源。CPU 确定性复现包含已显示 1000 ms、opacity 为 1 的 z12/z13/z14 三层来源。
- 北京 z15、倾角 60°、bearing 0°、2560×1305 的当前目标为 z13×15、z14×61、z15×3；下方约 1/3 地面采样中 99.1% 使用 z14 目标。已记录的 07:13 WebGPU 时序具有同一分布。
- `displayZoomGap` 衡量目标与实际来源差值；`levels` 为目标分布。近处理想质量、实际重叠层数与过期流水线成本需要各自指标。
- 实现位置、统计方法、编号图和验证边界见 [专题审计](../research/tile-overlap-and-pitch-audit-2026-09-15.md)。

## KYE 海面响应

在经度 124°、纬度 33° 的实测样本中，z5/27/12 和 z6/54/25 包含 ocean 面；z7/108/51 和 z8/216/103 返回 HTTP 204。204 目标使用有内容的祖先提供地理覆盖。

## 体验验证

公开资料与验收门槛：`docs/research/streaming-rebuild-public-sources.md`。

实际浏览器录像、帧时间、连续图像审查与回归记录：[道路宽度与快速交互修复验证](../evidence/streaming-rebuild/oversized-roads-fix.md)。

证据采用逐 RAF 帧间隔、60 FPS 目标 MP4、10Hz 图像/诊断与连续画面审查。覆盖统计与细节层级差分别记录；录像的实际编码帧率约 57–58 FPS。

2560×1305、DPR 1 的最终首屏快速交互、城市往返和真实手势分别通过 15、19、15 项断言。前两项运动帧 P99 为 17.7 ms、17.6 ms；手势前 25 秒活动段 P99 为 12.0 ms。初始化后的交互覆盖缺口为 0；缓存回访返回请求增量为 0。运动采样的层级差 ≤2 比例依次为 99.51%、97.69%、100%，最大层级差依次为 3、3、2。

1155 张 10Hz 连续图像、477 张关键窗口 60Hz 重采样图像及三张原始分辨率黄色区域峰值图已完成模型视觉审查。采样画面具有连续底图、道路、水面和雾边界；初始加载与运动中存在可见的渐进细化，巨大道路块与交互白块在最终采样中出现次数为 0。

实测首个完整覆盖采样为 324.0 ms，目标细节就绪为 1276.9 ms。环境为 i5-13600KF、RTX 4070 Ti、Windows、WebGPU、真实 KYE 数据与启用 HTTP 缓存的浏览器。CPU 瓦片资源估算峰值 217.805 MiB，GPU 255.999653 MiB，条目 384；GPU 用量接近 256 MiB 预算上限。HTTP 全冷、弱网、其他 GPU 和物理显示器逐帧呈现属于待验证环境。
