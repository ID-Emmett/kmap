# D036 天空背景与远景雾视觉契约

- 状态：Accepted
- 确认日期：2026-09-29
- 决策来源：人工负责人明确要求天空、雾和可见内容边界形成高德参考图所示的连续画面。

## 决策

- 本决策定义当前天空背景与主题天顶色契约；D025、D029 的距离雾和有效覆盖约束继续适用。

- 倾斜视角的天空属于场景背景。近处地面和建筑按正常深度关系遮挡天空；天空绘制不覆盖可见地图内容。
- 天空在屏幕可见区域内从底边的地平线色连续渐变到顶部的天顶色。渐变覆盖整片可见天空；平视时顶部保持清晰的蓝色系。俯视 `pitch=0` 时不显示天空。
- 天空底边由当前帧相机和雾完成吞没地图内容的位置确定，并随视角、缩放、平移、方位和视口变化。该边界采用可见内容边界语义，独立于数学地平线。
- 地平线色和雾末端色使用同一个解析后的主题颜色：现有 `MapTheme.fogColor` 优先，未配置时使用 `MapTheme.backgroundColor`。地面、矢量瓦片、建筑及卫星影像在远景雾末端收敛到该颜色；远景内容在进入纯天空区域前连续消失。
- `MapTheme` 增加可选天顶色配置 `skyZenithColor`。SDK 提供蓝色系默认值；Playground 的晴昼、深海、晴彩主题分别指定天顶色，并可在主题面板编辑。现有主题字段和 `setTheme` 调用方式保持兼容。
- 天空、雾与可见内容在同一渲染帧使用一致的相机和边界参数。WebGPU 与 WebGL2 使用 Three.js / TSL 共享渲染路径。
- 雾完成吞没前的地图区域保持有效覆盖；现有瓦片请求、来源所有权、缓存和资源预算契约继续适用。

## 验收边界

- `pitch=0/20/40/60/75`、连续俯仰、缩放、平移、方位旋转、视口变化和主题切换均验证天空渐变、遮挡、雾色接缝与远景消失。
- 矢量底图、纯卫星底图和卫星叠加状态验证远景颜色收敛与天空背景关系。
- 所有浏览器视觉、交互和性能验证在前台可见且当前激活的 Chrome 窗口执行，分别覆盖 WebGPU 与强制 WebGL2；证据包含实际画面、逐帧状态和控制台信息。
- 人工负责人依据参考图和真实交互画面完成最终视觉验收。
