# D035 卫星影像底图与按需矢量叠加

- 状态：Accepted
- 确认日期：2026-09-28
- 决策来源：人工负责人批准卫星底图方案，并确认全球概览保持平面、一键卫星进入纯影像。

## 决策

- 在单个 Web Mercator 世界平面上接入可配置 XYZ 栅格影像源。Playground 的默认影像源为高德 `style=6`、256 像素瓦片，原生有效层级按实测设置为 1～18。源配置独立于 `kyemap-js-api` 运行时。
- 影像拥有独立于 KYE MVT 的需求、请求、解码、GPU 资源、父子覆盖和回收路径。已就绪祖先影像覆盖尚未就绪的目标区域；新影像在帧边界接替。
- 底图运行状态含 `satellite`、`vectorLines`、`labels` 三个独立开关。卫星模式始终关闭矢量面与建筑绘制。纯卫星状态停止矢量请求、Worker 解码和绘制。
- 面板的卫星预设将三个开关设为 `true/false/false`；矢量预设设为 `false/true/true`。预设执行后，三个开关仍可独立调整。
- 已验证占位图片不能进入可绘制影像集合。影像最大原生层级由源配置限制；更高视图层级使用最高有效影像层级放大，并在验收中记录实际清晰度边界。
- 公共 API 增加栅格源配置、初始底图状态与运行期底图状态设置/读取；保留现有矢量 API、Three.js WebGPU/WebGL2 和 TSL 技术基线。

## 验收边界

- 全球概览指平面 zoom 0，单世界两侧保持 D034 定义的背景色。世界范围内的已就绪影像覆盖保持连续。
- 首次冷启动在首张影像准备前显示背景；若产品要求离线首帧完整影像，需另行批准随包提供的授权概览资源。
- 真实浏览器验收覆盖 WebGPU/WebGL2、z0～最高有效影像层级的双向连续缩放、慢网、错误与频繁开关切换；逐帧截图、覆盖、网络、Worker 和性能数据共同判定。
