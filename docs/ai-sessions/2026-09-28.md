### S2026-09-28-002 — 修复边界视角平移瞬移

- 会话类型：实施会话
- 关联范围：T049 / packages/map3d / docs
- 用户原话：

> 人工验收不通过，在图中的相机视角下，左键pan时，地图会瞬移跳动，交互问题。

- AI 结论：
  - 根因是平移射线求交的固定截断距离：图中视角为 zoom 0、pitch 0、中心 `(180, -85.051129)`，相机距离约 1.76e8 米，超过 `WORLD * 4`（约 1.60e8 米），中心射线与移动射线先后退化为水平截断；两点差值被放大到 1.6e8 米，位移立即触发经度钳制，表现为瞬移跳动。
  - 修复：`panViewByPixels` 与 `locationAtPixel` 的射线截断距离改为 `max(WORLD * 4, frame.distance * 4)`，低缩放与大视口下按真实地面求交；高缩放行为保持不变。
- 执行与验证：
  - 新增回归测试「最低缩放边界视角的水平平移按像素尺度移动，不产生瞬移」与「最低缩放边界视角的中心像素锚点等于视图中心」。
  - 区分度验证：临时回退截断距离后平移测试失败，恢复修复后通过。
  - 回归：`pnpm typecheck` 通过，`packages/map3d` 32 个测试文件 / 178 个测试全部通过。
- 后续动作：

### S2026-09-28-003 — 修复城市飞行路径越界

- 会话类型：实施会话
- 关联范围：T049 / apps/playground / docs
- 用户原话：

> 修复问题：最小层级平移后，点击飞往广州按钮，相机飞向的地方不是广州而是地图外空白地方，过几秒后突然瞬移到广州位置，现在地图只有一张没有重复的。也许是这里的问题，或者相机或者坐标。

- AI 结论：
  - 根因是 Playground 飞行路径仍保留世界副本时代的经度环绕差值：`((to - from + 540) % 360) - 180` 从西经或边界起点出发时会选择向西跨日期线的路径，中间经度超出 `[-180, 180]`。
  - 单世界钳制后飞行过程中的中心被钉在 `-180`，相机停在世界边缘（画面为地图外空白），直到 `progress = 1` 时 `setView(destination)` 才跳回广州。
  - 修复：`flightView` 的经度差值改为直接差值，飞行路径必然落在起终点之间，不越出单世界；地图侧不修改。
- 执行与验证：
  - 新增回归测试「从西经与边界视角飞往广州时路径不越出单世界」，覆盖 `-100`、`-170`、`-180`、`180` 四个起点。
  - 区分度验证：临时回退环绕差值后该测试失败（中间经度 -180.105），恢复修复后通过。
  - 回归：`pnpm check`（map3d 178 个测试 + playground 20 个测试 + 构建）、`pnpm ai:check`、`git diff --check` 通过。
- 后续动作：
