- 关联范围：用户直接授权的瓦片、道路、文字、交互和性能优化；用户要求忽略项目任务系统，任务状态文件保持当前记录。

- 验证：`pnpm check` 通过 194 项测试、类型检查和构建；真实 WebGPU/WebGL2 海陆坐标像素采样与连续运动通过。完整矩阵、网络重试事件、性能、冷加载及治理检查结果由 [验证报告](../evidence/maplibre-alignment/README.md) 和汇总记录。
- 边界：地图数据实际精度、道路转角实现范围和有限采样范围按报告列明；性能记录与原始硬件、浏览器和视口绑定。

- 实施结果：`StreamingEngine` 发布当前目标整数 `tileZoom`；线、面、建筑和文字的 `minZoom` / `maxZoom` 统一按该层级求值。连续 `viewZoom` 负责像素线宽插值、投影、相机尺度与碰撞位移。父级回退内容按目标层级求值。
- 验证结果：`pnpm check` 通过 SDK 185 项、Playground 19 项测试、类型检查和生产构建。真实浏览器 WebGPU 在 `view 6.84 / tile z7` 与 `view 7.09 / tile z7` 均显示道路，目标覆盖缺口为 0；WebGL2 在 `view 6.84 / tile z7` 显示道路，目标覆盖缺口为 0。双后端控制台警告和错误为 0。
- 正式状态影响：道路、面、建筑和文字的层级显隐具有单一目标瓦片层级来源；连续视图缩放保持视觉尺度职责。
