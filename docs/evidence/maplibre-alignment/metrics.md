# 性能面板指标说明

| 名称 | 当前含义与判读 |
| --- | --- |
| 驻留 | 当前参与显示的瓦片来源数。父级回退也计入。 |
| 预热 | GPU 已准备好、当前未显示的资源数。再次进入视野时可直接使用；包括预取与保留资源。 |
| 冷缓存 | 已下载响应或已处理 CPU 产物，仍需 Worker 处理或 GPU 准备的条目数。它与“首次访问且缓存为空”的冷启动含义不同。 |
| 命中 | 瓦片重新进入需求集合时复用了已分配的表面资源。统计对象包含可见、回退、预测需求。 |
| 未命中 | 新需求需要创建瓦片条目。它与 HTTP 请求次数具有不同计量边界。 |
| 命中率 | 命中 ÷（命中 + 未命中），累计统计。回访同一区域通常较高；持续浏览新区域通常较低。 |
| 条目 / 上限 | 当前所有阶段的瓦片记录数 / 允许记录数。达到上限触发回收或延后准入。 |
| 淘汰 | 为满足容量预算释放低优先级资源的累计次数。持续快速增长且命中率低，提示缓存周转频繁。 |
| 目标待就绪 | 当前目标精度尚未准备完成的数量。已有祖先时画面仍可完整。已确认空主源由回退规则处理。 |
| 主源为空 | 主瓦片返回无内容，海洋、边界、地名等辅助来源分别完成加载；辅助来源可用时目标仍具有可绘制内容。全部来源均为空时使用覆盖树的祖先资源。 |
| 覆盖缺口 | 目标区域连可用祖先或子级都缺少的区域数。加载稳定后应为 0。该指标表示瓦片资源覆盖；地理内容完整性另由来源契约与海陆像素采样验证。 |
| 显示层级 | 实际数据来源的层级分布。区域间存在不同层级是渐进加载的正常状态。 |
| 请求排队 / 活动 | 等待网络准入 / 正在处理网络请求的条目数。 |
| 上传排队 / 活动 | 等待 GPU 准备 / 正在等待管线准备完成的条目数。 |
| HTTP 次数 / 重试 / 取消 | 实际共享请求、失败重试、失去需求后取消的累计统计。 |
| CPU / GPU 字节 | SDK 登记的瓦片缓冲、几何和阶段预留估计。共享响应缓存、字形以及浏览器和驱动内部内存单独计量。 |
| FPS | 根据实际浏览器帧间隔计算的帧率；受显示刷新、浏览器调度、后台状态及场景影响。 |
| CPU 帧耗时 | 主线程一次更新与提交花费的时间。GPU 执行和帧调度等待具有独立时间范围。 |
| P95 | 95% 的采样值不超过该值；可用于观察多数慢帧。仍需结合最大值与长任务检查。 |
| Draw calls / 三角形 | 一帧的绘制调用数 / 提交三角形数。相同视觉质量下通常越少越有利。 |
| 文字候选 / 显示 / 布局 | 参与筛选的标签、通过碰撞的标签、布局 CPU 耗时。部分候选因碰撞正常隐藏。 |

瓦片预热、冷缓存与瓦片层级是不同维度。pan 后海岸线变细，通常表示目标级数据接替了祖先回退；当前模板保证每个地面采样点只有一个来源负责绘制。
