# KYE 近岸海陆权威验证

日期：2026-09-20。入口：`http://127.0.0.1:6661/`。人工约束：所有地图数据保持 KYE。人工验收输入：“直接完成，测试没问题了”。

## 来源规则

有效主响应独占对应瓦片区域的海陆边界。主源 water 几何覆盖水面，其余区域具有陆地语义；有效主响应中的空水面层同样保留陆地。主响应无内容时才加载 `kye_water` 与 `kye_water_ocean`，作为 KYE 海洋回退。

`onlyWhenPrimaryEmpty` 同时约束请求准入与 Worker 解码。主源区域的建筑、道路和海陆使用相同 canonical 瓦片；GPU 准备完成后由模板整体接替覆盖区域。来源选择发生在加载、解码阶段，逐帧使用已合批几何。有效主瓦片省去两类海洋请求和几何处理，资源预算保持原值。

此机制对应成熟瓦片引擎的区域所有权、有效内容与回退分离原则。MapLibre v6.9.1 `tile_manager.ts` 按数据可用性保留目标与替代瓦片，`draw_fill.ts` 通过瓦片模板裁切。KYE 跨来源的海陆优先级由应用的数据契约明确配置。

## 根因证据与回归

赤柱 `16/53561/28621`、`16/53560/28620` 共 50 座建筑中心，在主源与详细海洋几何中全部为陆地，在 z6 基础海洋中全部为水面。粗海洋参与这些有效主瓦片的绘制，会覆盖道路、建筑下方的陆地。数据 URL、响应大小、SHA256、建筑坐标及水面分类见 [来源审计](coast-source-audit.json)。

自动回归对两块真实瓦片各取 48×48 个海陆采样点，组合结果与主源一致；50 座建筑中心均为陆地。网络测试核查有效主源省去海洋请求、204 启用回退、共享祖先 URL 只读取一次。Worker 测试包含有效空 MVT 层的陆地语义。

台湾测试持续覆盖主源 204、详细海洋局部覆盖和 204、连续视图 zoom、岛屿孔洞、祖先回退。主源缺失区域的精度由 KYE 可用回退数据决定；完整高精度海岸的提供范围属于数据源契约。

## 实际浏览器结果

WebGPU，2136×1318、DPR1。赤柱 zoom 7.34、10、14、16、17、18 六个场景均收敛，目标缺失与覆盖缺口为 0。z14 及以上隐藏建筑、线和文字后，读取真实地表像素；50 个建筑中心与 3 个真实水面控制点中可见的采样全部符合海陆分类。z7.34、z10 使用概览截图检查；单体建筑在该尺度的像素足迹不足以用于地面分类。

240 帧连续 pan、zoom、旋转的地面采样失败帧为 0。独立 8 秒性能采样为 169.88 FPS，帧间隔 P95 6.0 ms、CPU P95 4.2 ms，瓦片 CPU/GPU 峰值约 41.7 / 15.4 MiB，覆盖缺口为 0。测量绑定此设备、视口和轨迹。

台湾在 1887×1022 的五个场景全部收敛，含同为 z7 来源的不同视图 zoom；固定海陆坐标及 240 帧运动采样失败为 0。两个专项的地图错误事件均为 0。
