## 海面留白的因果与当前合成规则

用户截图的视图 zoom 为 6.84、7.34，显示源均为 z7。KYE 详细海洋的空间范围是稀疏的：`kye_water_ocean/7/108/55` 返回 200、11,784 字节、313 个面，在瓦片内部 32×32 采样中覆盖 369 点；相邻 `7/109/55` 返回 204。`kye_water/6/54/27` 的基础几何提供相应外海与岛屿孔洞。数据 URL、字段、面积、采样和 SHA256 见 [来源审计](ocean-source-audit.json)。

当基础海洋设置 `maxZoom: 6` 时，其着色范围在视图 zoom 7 截止。详细源在服务区域外没有海洋面，陆地底色便在这些区域可见；边界沿详细源几何分布，具有不规则形状。HTTP 成功和瓦片模板覆盖完整，分别证明请求成功和资源区域可绘制；海洋内容的完整性另行验证。

当前 `mapSource.ts` 定义基础海洋与详细海洋的独立来源。基础海洋持续参与全部视图层级的合成，详细海洋按可用内容补充。源的最大数据层级为 6、7，几何在 Worker 中映射到目标地址。主源 204、详细源 204 和基础海洋内容各自登记、处理。基础和详细海洋合入同一填充批次；共享 URL 缓存复用响应，海岸几何无需逐帧重建。

海洋来源合成使用同色水面几何的联合边界，保留输入中的陆地孔洞。实际边界精度由两个来源共同决定；上游主源缺少的道路、建筑和地名取决于数据提供方的内容。

## 瓦片、道路、文字与交互

- 主瓦片采用 canonical 身份；Worker 产物经 GPU 管线准备后发布。父到子完整模板按采样点分配唯一来源，MVT 缓冲保留边界覆盖。不同区域可采用不同来源层级；父级被目标级接替时，海岸几何精度可能增加。
- 请求、Worker、GPU 准备、响应缓存与淘汰具有独立预算。共享模板节点与响应体减少重复编译、拷贝和解析。CPU/GPU 瓦片预算各 256 MiB。
- 道路为连续折点带、受限 miter、butt 端点和横向解析抗锯齿；z14 以上保留 MVT 原始折点。Playground 宽度采用 OpenFreeMap Liberty 的指数缩放曲线，换算到地表后接受透视投影。MapLibre 官方 `line-width` 单位为 pixels；SDK 也支持米制。道路宽度随 zoom 变化，投影宽度随距离变化。高德内部实现未作为已验证依据。
- 文字采用 SDF、持久身份、世界锚点和 200 ms 连续显隐；atlas 更新保留身份与透明度。国家、省名、省会按范围显示，省会图标为红圈。鼠标滚轮保留指针处的地理锚点。
