# 平面/地球、Inspector 与加载稳定性验证

验证入口为 `http://127.0.0.1:6661/`，使用真实 KYE 网络和实际浏览器 WebGPU/WebGL2。正式数据、源码 SHA256 和原始 JSON 路径位于 [verification-summary.json](verification-summary.json)。

## 当前实现

- 城市使用平面；z4.5～5.5 连续形变为地球。覆盖、片元和文字使用球面可见半球，经度映射到相机附近的世界副本。
- 平面采用 CPU 双精度 model-view 矩阵。公共边量化到 1/64 设备像素网格中心，量化误差最多 1/128 像素。该参数由 z20/z22 跨浮动原点、每帧 0.25 像素的实际双后端回归验证；本机 WebGL 报告 SUBPIXEL_BITS=4。
- 调色板采用 256 项颜色/参数 BufferNode，共 8 KiB。新材质编译保持缓冲引用；回归测试覆盖同帧先绑定调色板、再编译材质的顺序。
- 陆地色由独立底面绘制；平面使用一个批次，几何占 92 字节。默认背景、雾为 `#dbdeff`，陆地为 `#e6f4f3`。
- 国家 z0 起，省会与直辖市 z5 起，普通城市 z7 起。国家在 z6 退出，低缩放保留 `iso_a2=CN`。层级依据真实 KYE `class/capital` 字段；z5 fixture 测试覆盖北京和宜昌的优先级与出现门槛。
- 铁路 z10 底线 40 米、透明度 0.38，虚线 18 米、透明度 0.45；隧道和渡轮分别使用 0.5/0.55 透明度。
- Inspector 默认启用，支持三主题、每项地图元素与文字样式、文字总开关、独立图标颜色/尺寸/间距。字形以墨迹边界对齐图标；控件回填采用静默同步。主题配置按主题独立保留，重置具有明确作用范围。
- 文字样式参考 Mapbox 官方 v3.14.0 的 anchor、size、halo、color 和 sort-key 定义；原始文档摘要与 SHA256 见 [mapbox-reference.json](mapbox-reference.json)。

## 验证方法

`pnpm check` 包含类型检查、144 项 SDK 测试、16 项 Playground 测试和构建。治理与差异检查使用 `pnpm ai:check`、`git diff --check`。

浏览器矩阵由 `apps/playground/src/inspectorBenchmark.ts` 驱动：2560×1305、DPR1，Inspector 启用；WebGL2 为单采样，WebGPU 使用默认 MSAA。本机 GPU 为 NVIDIA RTX 4070 Ti，WebGL 经 ANGLE/D3D11。

每个后端包含 35 个静态场景：0°/75° 倾角的十个过渡缩放、日期线两侧及整周经度、三主题各自 z10/z16.3/z20/z22。静态截图与逐帧回读独立于 30 秒连续 pan/zoom/pitch/bearing/主题性能计时。最终数据由上面的 JSON 索引给出。

冷加载在文字关闭时逐渲染帧读取 240px 宽缩略图；连续三帧中，中间帧近白像素比例超过两邻帧 1.5 个百分点时记录异常。该指标用于检测单帧大面积泛白；局部线缘像素由近景边缘测试与视觉检查补充。WebGL2 单采样保留正常的像素阶梯，亚像素边缘位置误差与大范围位置抖动分别测量。

原始证据包含每帧图像、帧时序、覆盖缺口、资源峰值及错误。运行 `python docs/evidence/map-inspector/analyze.py <WebGL2 JSON> <WebGPU JSON>` 可生成摘要、静态联系表与冷加载联系表。首次网络到达决定瓦片首次出现时间，冷加载测量包含此阶段。

## Inspector 控件回归

在默认入口通过真实控件验证：三主题连续切换五次，各次主题与运行时颜色一致；陆地和水面独立改色、主题内配置保留、元素隐藏、主干道线宽 1.7/透明度 0.6、建筑高度倍率 1.5、字号和图标大小 18、独立图标颜色均生效。文字总开关关闭后 placed 为 0，重置恢复显示。静止时布局计数保持稳定。

最终页面为北京 z15、倾角/方位角 0、晴昼默认主题，全部文字开启；三个环境颜色与用户指定值一致。Inspector 数字输入即时同步属于浏览器矩阵之后的控件修改，已完成真实输入补验与完整 `pnpm check`。摘要中的 `browserSourceSha256` 对应矩阵运行源码，`sourceSha256` 对应最终控件补验源码。

原生 806×1272 内嵌视口的本轮 UI 回归中，帧间隔约 1000 ms、地图 CPU 约 0.8 ms；暂停地图渲染后的独立 RAF 两次间隔为 1005.9/1005.8 ms。该观察单独记录为浏览器帧调度边界；上表使用固定视口的独立性能轨迹。原生视口的主题、输入和拖动事件均完成应用。

最终检查：`pnpm check`（160 项测试、类型检查与构建）、`pnpm ai:check`、`git diff --check`。用户可从 Inspector 的 Parameters 面板继续进行产品观感验收。
