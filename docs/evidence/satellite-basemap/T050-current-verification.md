## 慢网、失败和交互

- `T050-*-fallback.json`：目标层级请求延迟 500 ms，按坐标注入首请求 HTTP 503，随后执行 16 次快速平移、45°/75° 倾斜与旋转。WebGPU 2226 帧、WebGL2 2171 帧；覆盖缺口、零影像绘制帧、矢量请求均为 0。注入失败分别为 17/15 次，重试分别记录 48/45 次。早期影像覆盖来自 z1 祖先，收敛后目标 z12 自有影像完成接替。`fallback-early/recovered/pitch/rapid-pan-pitch.jpg` 保存画面。
- `T050-*-switch.json`：真实 Inspector 面板依次点击“一键矢量”与“一键卫星”，再快速切换线和文字十轮。纯卫星采样 WebGPU 690 帧、WebGL2 688 帧，影像零绘制帧与覆盖缺口均为 0；一键卫星后和最后纯卫星稳态的新增矢量请求均为 0。矢量预设显示面/建筑；卫星预设关闭面/建筑与 Worker。`T050-*-z15-lines.png` 与 `T050-*-z15-labels.png` 显示线路和文字分别独立叠加于影像。
- `T050-*-preview.json`：生产双文件 Preview 的 WebGPU/WebGL2 z15、独立线、独立文字、z0 与 z20 均成功渲染；纯卫星阶段矢量请求为 0。
