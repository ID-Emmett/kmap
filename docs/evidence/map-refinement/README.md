# 2026-09-16 地图文字、球面与道路验证

## 当前实现

- POI 按 KYE `level` 显示；Playground 在 z6 及以上复用有界缓存中的 z6 `place` 数据。真实字段与图层样本见 [数据核验](data-audit.json)。
- Worker 分别保留点与道路候选；视图层级和投影裁剪先于屏幕候选限额。48px 单元保留 4 个高优先候选，布局上限 2,000，显示上限 256。
- 稳定标识保留点锚点和 2 秒淡入状态；道路文字方向由 GPU 每帧投影。SDF、碰撞、名称去重和 64ms 布局调度共用一个字形批次。
- 矢量面、线路、地名共用球面投影、覆盖调度和场景。z4.5–5.5 连续改变同一几何的曲率，最低缩放展示完整球体。球体使用地图基础色，极区按水体与陆地基础色补齐。
- 低层级三角形和线路在 Worker 细分；曲面细分缓冲计入 CPU/GPU 预算。城市面和线使用平面材质变体。
- 相同样式道路在二度端点连接并按半像素误差简化；三度及以上路口保留拓扑。共享折点采用有界 miter，路径端点为圆帽。桥梁独立执行描边与填色顺序。
- Worker 按数据层级筛选启用图层；道路宽度与虚线表使用 32/64/128 容量档位复用节点图；静止调度轮询间隔 64ms，异步完成事件立即激活队列。
