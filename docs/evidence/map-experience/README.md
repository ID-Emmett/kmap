# 球面地图、文字、稳定性与主题验证

日期：2026-09-17。实际入口：<http://127.0.0.1:6661/>。

## 当前实现

- 所有缩放级别使用球面坐标。矢量面、道路、建筑和文字共用球面投影与可见性约束；射线与球面求交驱动 pan，经度连续累计。完整一周的测试与截图覆盖 360° 经度范围。
- 距离雾与球缘薄雾连续作用于球面内容，CPU 覆盖与 TSL 绘制采用一致的距离约束。道路按投影计算米制宽度，合并后的低级别线路保留曲线细分。
- 文字提供字号、密度、图标开关，以及图层/类别颜色和描边配置。九类 SDF 图标与文字共用 atlas 和绘制批次；游乐场配置即时生效。
- 目标层级使用向下 0.18、向上 0.08 zoom 的滞回区间。文字投影预算在可见瓦片间分配，候选缓存、位置保留及小位移布局节流控制运动成本。
- 面板提供晴昼（默认）、深海（深色）、霓彩（绚丽）。地图面、道路、边界、建筑、文字、图标、雾和背景支持切换；颜色 uniform 为 128 项、2 KiB，切换复用瓦片数据和几何。
- 显式 WebGL2 模式默认单采样，线与字形采用解析抗锯齿；`renderer.antialias: true` 启用 4x MSAA。WebGPU 默认使用 MSAA。全局 palette 内存单独计入诊断。

每个后端覆盖三套主题 × 城市 z15、建筑 z16.3/pitch60、雾 z5.5/pitch75、地球 z0、日期变更线 z3。30 个静态场景均完成目标/字形加载收敛；两段 45 秒 pan/zoom/pitch/bearing 与主题切换计时均为 0 覆盖缺口、0 空目标、0 运行错误。CPU/GPU 瓦片预算各为 256 MiB；表中峰值包含独立截图采样阶段。

每个后端保存 197 张图像：15 张静态场景、120 张连续运动图像、49 张 z6.2→4.2/pitch75 过渡图像、13 张完整一周图像。394 张图像均完成模型视觉检查，检查项为地图内容连续、球缘雾连续、道路宽度、文字和主题颜色。截图宽度为 1280，渲染与性能计时保持原生视口。

独立 12 秒视觉采样以约 10 Hz 截图，WebGL2 1,688 帧、WebGPU 1,759 帧，覆盖缺口均为 0。截图回读具有额外开销，该阶段帧率单独保存在 JSON。

## 面板与真实输入复验

在普通入口、1280×720 默认视口，以真实拖动与滚轮完成城市平移/缩放。文字调至 105%、密度 128、关闭图标，医疗颜色设为 `#ff3366`、描边 1.5；SDK 运行配置与控件值一致。重置后字号 100%、密度 256、图标开启、类别覆盖清空，颜色/描边控件同步复位。三套主题均通过面板切换和截图检查。

z2 球面从经度 179.9° 真实向左拖动，惯性停止后经度为 281.186541°，覆盖收敛为 0 缺口、0 错误。此次大跨度首次访问的中间面板记录为 2 个目标待加载、2 个覆盖缺口，后续读数为全部就绪。冷网络下新区域的详细瓦片到达时间受真实请求影响。

交付页面为默认晴昼主题和北京初始视图；临时视口已重置。最终页面复验未记录 console warning/error。

## 性能依据与验证边界

[抗锯齿对照](aa-comparison.json) 使用同机同视口北京 z15 的实际帧采样：半浮点 4x MSAA 为 72.89 FPS，半浮点单采样为 170.01 FPS，unsigned-byte 4x MSAA 为 76.80 FPS。对照每组采样 4 秒；正式矩阵使用 SDK 构造参数并重新加载页面。

上述帧率适用于本机、此视口和记录轨迹。强制 WebGL2 的单采样配置使建筑/面的轮廓具有对应的采样精度；使用者可显式选择 MSAA。建筑显示门槛为 zoom 15.74，跨越门槛时建筑进入或退出画面。自动覆盖计数、截图视觉检查、物理显示器观感及人工产品验收分别具有各自的验证范围。
