# 海面、虚线、文字与地球验证

## 实施内容

- 主源为空时加载 `kye_water` 的真实海洋底图；7 级以上加载 `kye_water_ocean`。补充来源按 canonical URL 共享请求，响应缓存上限 8 MiB / 128 项，租约控制取消，祖先海洋面按子瓦片包围盒筛选。
- 线样式查表在顶点阶段完成，宽度、虚线数组、样式索引与 zoom 范围采用 flat 插值。导数在裁剪之前求值；亚像素虚线趋向平均覆盖。实线通过分支直接使用完整覆盖。
- Playground 20 个线样式的两张表占 640 字节/来源；表尺寸由实际图层数量确定。此项为数据结构大小，GPU FPS 由实际浏览器测量。
- [文字系统](../../research/map-label-system-2026-09-16.md)包含真实中文数据、SDF、碰撞、优先级、去重和有界缓存。
- 低缩放通过真实 KYE 根瓦片、Worker 栅格化图集、球面网格、大气与合批星点显示地球。4.5–5.5 级渐变衔接平面；最低缩放完整球体适配横屏、竖屏及超宽视口。根瓦片提供概览精度。

## 已验证事实

- 截图对应主源 `7/108/54`、`7/107/55`、`7/107/56`、`7/106/56` 均返回 HTTP 204；同址专用海洋源返回 HTTP 200，见 [网络审计](sea-holes-audit.json)。
- 专用 `7/108/54` 的 797 个海洋 Feature 在 1,024 个采样位置上与三角化产物一致，其中 960 点在水面内。详细源的东南覆盖边缘由真实 `kye_water/6/54/27` 祖先补足，岛屿与海岸几何按源数据精度显示。
- 17 级 overzoom 对海洋面执行包围盒筛选，测试样本保留少于 10 个 Feature，中心海面采样成立。
- 自动测试覆盖海洋组合、并发请求共享/取消/重试、CJK 字形、名称字段、碰撞网格、父子锚点互斥、布局保留、浮动原点、完整地球与资源释放。
- 双后端 TSL 节点均生成线、字形、球面、大气与星点着色器。此项验证源码生成，驱动编译和 GPU 输出由浏览器验收。

## 浏览器验收状态

本次浏览器自动化入口返回 `unsupported Codex auth method: apikey`。Windows Computer Use 在读取 Chrome 状态时因无法可靠确认当前 URL 而停止；自动审批检查拒绝该操作。本次实际浏览器验证与 WebGL2/WebGPU FPS 对照待执行。

已接入同场景自动采集入口：

- WebGPU：`http://127.0.0.1:6661/?capture=stability`
- WebGL2：`http://127.0.0.1:6661/?renderer=webgl2&capture=stability`

矩阵包含两处海面截图视图、铁路、中文地名/POI、边界、地球衔接、完整地球和日期变更线。每个场景保存稳定截图、连续 pan/zoom 的原始帧时间、覆盖缺口和诊断。追加 `&visual=1` 时采集 5Hz 运动图像；帧率对照使用默认模式，时序画面审查使用图像模式。代码路径为 `apps/playground/src/stabilityBenchmark.ts`；输入类型为 programmatic views，自动结果与画面审查分别记录。

人工视觉验收项：海岸与海面连续性、瓦片替换、虚线时域稳定性、文字清晰度/碰撞/方向、球面纹理方向/极区/衔接、双后端同视口运动帧率。当前性能优化幅度与用户截图的最终视觉结果以该项实测为准。

命令和最终状态见 [verification-summary.json](verification-summary.json)。原始下载与生成的 shader 位于本地 `docs/evidence/map-stability/`，测试 fixture 保存在 `packages/map3d/test/fixtures/`。
