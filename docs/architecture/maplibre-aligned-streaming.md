# 瓦片覆盖、准备与绘制

更新日期：2026-09-20。范围为人工授权的瓦片、道路、文字与交互优化。

## 数据身份与阶段

每个主瓦片具有唯一 canonical `z/x/y`。世界副本共享数据和几何。HTTP 204 登记到对应来源，辅助来源继续按自身范围完成读取。组合来源全部无内容时，覆盖树在真实祖先地址寻找可绘制资源。辅助来源具有独立的最大数据层级和图层名；Worker 按目标地址映射其坐标。`primaryEmpty` 单独记录主源无内容，`empty` 表示组合包无内容。

状态顺序为 `queued → fetching → decoded → painting → upload → preparing → ready`。`decoded` 保存已经下载的响应包，`painting` 执行 Worker 解析与几何处理。`preparing` 创建资源并等待 Three.js `compileAsync`。只有准备完成的资源进入可绘制索引。发布发生在帧边界。

空响应、网络失败、CPU 数据就绪和 GPU 可绘制分别登记。失败遵循退避；当前显示资源具有保护引用。取消最后一个 URL 订阅才取消共享网络请求。相同响应体在组合包中只保存一次，并在 Worker 中只解析一次。

## 需求与覆盖

目标层级由视图 zoom、缩放滞回和数量预算确定。相同 zoom 的常规 pan 保持目标层级。当前可见目标、必要祖先、同级邻居预测分配独立调度机会。

预测名额中为最多 8 个概览祖先保留独立空间，剩余空间服务同级邻居与运动预测；概览需求持续覆盖当前视域及两级缩小视域。

覆盖树优先选择目标资源；目标等待期间复用已有子级或最近可用祖先。每个逻辑区域具有唯一来源。不同地理区域可以采用不同数据层级。目标资源准备完成后接替对应区域。

海岸线在祖先接替为目标资源时可能变细；这是源几何精度的变化。预热与冷缓存表示资源准备状态，与数据层级相互独立。所有来源均为空的目标使用有内容的真实祖先，诊断 `primaryFallbacks` 列出地址关系。KYE 海洋源最高数据层级为 7，主源无内容的台湾东岸也由该来源提供独立海岸线；道路与建筑细节取决于主源实际内容。

Playground 的主响应有内容时，其瓦片区域的海陆边界由主源独占；水面以外的区域具有陆地语义，水面层为空也属于有效内容。`onlyWhenPrimaryEmpty` 在请求和 Worker 解码两处执行。主响应无内容时，`kye_water` 提供基础水面，`kye_water_ocean` 按实际空间范围补充，分别按最大数据层级 6、7 重投影，并合入同一填充批次。海洋回退的可见性随已加载内容保持连续，源数据层级负责精度选择。HTTP 200 表示成功响应，HTTP 204 表示该来源无要素；来源的空间完整性属于数据契约。主源缺失区域的海岸精度由 KYE 回退输入决定。来源选择在加载/解码阶段完成，帧渲染使用已准备的合批几何。

## 模板所有权

所有可绘制来源按父到子写入完整矩形模板，子级编号覆盖父级编号。填充与线条逐采样点测试对应编号。每个采样点只有一个来源通过模板测试。

模板角点从统一 XYZ 格网使用双精度计算，再转换为相对浮动原点的 Float32。模板采用半个设备像素的保守栅格边界，处理不同层级边界形成的 T 形交点与 MSAA 采样精度。来源排序确定重叠采样点的归属。内容使用 MVT 的边缘缓冲；该策略要求输入几何包含合理的瓦片边缘缓冲。

建筑按逻辑覆盖区域裁切底部锚点。地面、线条、建筑与文字使用独立的绘制顺序。Three.js r185 WebGPU 绘制通道先绑定模板编号 0，再绑定各来源编号。

## 资源边界与性能

| 资源 | 默认上限 |
| --- | --- |
| 目标 / 总条目 / 预测需求 | 128 / 256 / 32 |
| 请求 / Worker / 待上传产物 | 12 / 4 / 8 |
| 瓦片 CPU / GPU 预算 | 各 256 MiB |
| 单个网络响应 / 组合包 | 16 MiB |
| 独立共享响应缓存 | 8 MiB，128 条 |
| 独立共享网络预留 | 32 MiB |

内存准入先淘汰低优先级、无保护引用的资源，再开始工作。GPU 准备每次处理一个资源。网络读取、Worker transferable、几何合批、共享模板材质、共享节点图和固定 BufferNode 控制重复工作。内存指标是 SDK 登记与预留估计，浏览器、驱动与字形 atlas 有独立的资源范围。

## 道路、图层与文字

道路使用连续中心线带、共享折点和受限 miter，端点为 butt。近景 z14 及以上保留 MVT 原始折点。Playground 道路宽度参考 OpenFreeMap Liberty 的指数插值；Kmap 256 瓦片尺度相对 MapLibre 512 尺度将 stop 层级平移一级。宽度换算到地表后参加透视投影。SDK 同时支持米与 CSS 像素宽度。

KYE 土地覆盖遵循官方 `landuse_grass` 的 `subclass != grassland` 条件；城市绿地按数据类别显示。省名、首府和国家名称使用独立缩放范围。首府图标为红色圆环。

文字使用 SDF atlas、单实例批次、字号与 DPR 决定的采样宽度。跨瓦片身份与世界锚点独立保存。显隐从当前透明度在 200 ms 内连续过渡，字形 atlas 重建时更新放置状态。标签碰撞布局与逐帧相机投影分离。

滚轮缩放保留鼠标处的地面锚点；连续滚轮输入合并处理。
