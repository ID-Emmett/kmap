# Nova Streaming Map Architecture

更新日期：2026-09-15

## 生产入口

`Map3D` 使用 `packages/map3d/src/streaming/engine.ts` 中的 `StreamingEngine`。Playground 通过 `@nova/map3d` workspace 依赖接入 SDK。

```text
ViewState + PerspectiveCamera
→ 视锥与距离约束四叉树
→ 当前可见需求 + 相邻预取 + 飞行预取
→ 有界请求队列
→ KYE XYZ MVT
→ Worker / VectorTile / OffscreenCanvas
→ 面图层 ImageBitmap + 线段实例 TypedArray
→ Three.js Texture / 实例几何 / MeshBasicNodeMaterial
→ WebGPU / 共享 TSL 雾
```

## 模块职责

| 模块 | 当前职责 |
| --- | --- |
| `address.ts` | XYZ 地址、世界副本、祖先关系和 URL 归一化 |
| `selection.ts` | 视锥剔除、地面距离限制、投影尺度 LOD |
| `engine.ts` | 需求优先级、请求生命周期、缓存、显示覆盖和回收 |
| `paint.ts`、`paint.worker.ts`、`workers.ts` | MVT 解码、图层过滤与 CPU Canvas 路径绘制、可转移位图 |
| `surface.ts` | 共享平面、纹理资源、TSL 距离雾与确定性销毁 |
| `lines.ts`、`lineSurface.ts` | 中心线解码与亚像素简化、实例胶囊、当前视图线宽、共享 TSL 节点图 |
| `coverage.ts` | 互斥化地理覆盖面积，消除嵌套区域重复计数 |
| `diagnostics.ts`、`samples.ts` | 队列、内存、覆盖、实际采样与时间序列 |

## 数据与资源

- 输入为标准 XYZ MVT；经度世界副本在网络地址中归一化。
- Worker 按 fill 图层配置绘制面纹理；line 图层生成按样式顺序排列的中心线实例与颜色、透明度、宽度和层级范围。
- 线宽以 CSS 像素存储，TSL 使用 `2^(dataZoom-viewZoom)/256` 转成瓦片局部坐标；同一视图中，各数据层级使用相同地面宽度。
- 线段使用胶囊距离场圆端点、抗锯齿和瓦片边界裁剪；节点图共享，对象组保存独立缩放参数。中心线解码结果在描边和填色之间复用，TypedArray 按精确容量分配。
- 数据层级按 256 CSS 像素地图瓦片语义计算。数据源最细三级的面纹理为 512 × 512，其余层级为 256 × 256；道路通过独立线段实例保持当前视图的像素宽度。
- CPU Canvas 上下文采用 `willReadFrequently: true`；输出 ImageBitmap 通过转移所有权交给主线程。
- 网络请求并发上限为 12，Worker 并发上限为 4，单帧上传上限为 1 张纹理。
- 默认 CPU 与 GPU 瓦片预算各 256 MiB，条目上限 384；CPU 计入位图及几何数组，GPU 计入纹理 mipmap 与实例属性。地址需求具有独立条目上限；位图与几何按实际驻留字节执行上传准入。
- 创建条目前检查硬上限；当前必要需求可替换尚未准入的等待条目及未显示的就绪缓存。预测需求可替换未显示、未准入且需求优先级更低的就绪缓存。已显示条目、执行中的流水线与本轮已准入需求受保护。
- 地面截止半径内、低于当前视图整数层级至少两级的数据具有缓存回收优先保护，为方位和倾角变化保留基础覆盖。
- 当前视图下三级与四级在地面截止半径内执行全方位预热，其优先级随地面距离递减；预热仍受同一距离、条目与字节预算限制。
- 选片与资源上传分配到不同帧；预热结果在预算不足时释放，当前视图使用显示保护和回收预算。
- 上传队列先提交当前目标及必要近层覆盖，再按数值优先级提交预取资源。
- 纹理提交前回收未被显示或需求保护的 LRU 资源。纹理、材质和位图均有销毁路径。
- 204 响应登记为空数据；显示覆盖继续寻找有内容的祖先。空响应记录按条目预算管理，纹理字节回收保留这些记录。
- 4096 项已结束键集合约束普通预热的重复工作；当前目标、必要祖先与两级覆盖邻接环可重新加载。当前覆盖上传可以回收未显示的预取资源。
- 请求失败具有有限重试与结构化错误事件。

## 显示与交互

- 已就绪祖先在子级加载期间提供底图；子级显示采用 140 ms 淡入。
- 覆盖解析遍历完整祖先链。请求集合包含当前目标、两级覆盖、三级与五级基础覆盖；204 记录向上扩展有内容的祖先需求。两级覆盖的邻接环持续预热，为平移和方位变化提供提前量。
- 缩小期间，已显示的相邻细层级持续覆盖已有区域；完全覆盖目标的细级集合直接保留。就绪目标接替时执行淡出。
- 视图缩小速度用于预测未来 0.6 秒的覆盖需求，预测缩小幅度上限为 1.5 级；相邻父级、当前细节和地图基础覆盖具有独立优先级。预测父级具有重新加载资格与缓存保护。快速缩小期间优先提交覆盖，静止 150 ms 后恢复细节优先级；其他状态的请求批次为当前细节保留槽位。
- 自由缩小预测同时预取未来叶片、父级和再上四级的广域覆盖；广域预测具有 900 ms 时效、重复加载资格和回收优先保护，支持反复缩放时的连续地理覆盖。
- 相机按浮动原点更新。地面距离与 TSL 雾使用同一中心和截止半径。
- 滚轮采用 80 ms 时间常数的指数插值，约 240 ms 完成输入量的 95%；60/120/170Hz 的同一时刻轨迹与最终 zoom 由回归测试验证。
- 倾斜画面的远方层级由投影尺度降低，距离截止范围约束选片和邻接预取。
- `Map3D.prefetchViews(views, options)` 接受未来视图、预取时效与优先级。
- Playground 城市飞行采用 van Wijk / Nuij 双曲函数路径；路线概览与目的地细节在飞行期间有显式预取时效。已知路径以 0.5 秒和 1.1 秒前方相机视图预取；显式预取更新后的 1.6 秒内，由该路径提供运动预测。
- 面板保留帧、请求、Worker、上传、缓存、资源、覆盖和相机指标，提供城市飞行、60 秒验收、首屏与快速交互验收、手势录像和 JSON 导出。
- 录像按浏览器编码器能力选择 H.264 或 VP8，证据文件使用对应容器扩展名；DOM 诊断属性提供统计摘要，原始采样保存在导出数据中。
